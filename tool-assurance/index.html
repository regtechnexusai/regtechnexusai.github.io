Tool Assurance & Evidence Register

This register explains the intended purpose, publicly described data boundaries and evidence requirements of RegTech Nexus AI review-support tools. It is a transparency register—not an audit opinion, security certification, legal opinion or claim that every function has been independently tested.

How to interpret this register

Evidence boundary: entries summarise public descriptions and identify validation needs. They do not mean that a live functional test, penetration test, privacy assessment or independent assurance engagement has been completed. Where evidence is not recorded, the status is “not verified by this register.”
Methodology

What the tool intends to assess

Purpose, inputs, rules or method, expected outputs and intended users should be described clearly enough for a reviewer to challenge the result.

Functionality

What must be tested

Representative workflows, boundary conditions, calculation examples, error handling, exports and browser behaviour require repeatable test evidence.

Data & security

What must be substantiated

Processing, storage, network requests, browser storage, third-party services, retention and access statements should match observed implementation and documented controls.

Regulatory change · Human review

AlfiQ Regulatory Change Impact

Early-stage browser-based decision-support prototype for comparing earlier and revised regulatory text and organising preliminary human review.

Current method and capability
Exact paragraph matching after whitespace normalisation; highlights added and removed paragraphs and surfaces potential obligation signals using keyword heuristics. These signals are prompts for reviewer triage—not legal interpretation, source authentication or a determination of applicability.
Input and data boundary
Users paste text extracts and source notes into the workspace. Use public, synthetic or otherwise non-sensitive material only. Browser-local processing and absence of external transmission must be confirmed by technical network/storage testing before making a security or privacy assurance claim.
Not currently evidenced as live capability
Automated regulatory monitoring, authenticated source ingestion, production AI interpretation, cross-tool data transfer, shared case management and institutional integrations are not established by this public prototype.
Minimum evidence to retain
Versioned source copies and citations; representative comparison test vectors; expected/actual added and removed paragraphs; heuristic false-positive/false-negative review; browser network and storage inspection; export and reset tests; reviewer name/date/decision; release and change history.
Verification status
Public page and source logic reviewed for this register. Independent security testing, browser data-flow verification, full functional validation and institutional suitability are not verified here.

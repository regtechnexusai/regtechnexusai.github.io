Browser-only processing

এই static calculator-এর salary এবং pension input browser-এর JavaScript-এ locally process হয়। এই tool salary input কোনো backend database-এ পাঠায় বা সংরক্ষণ করে না এবং analytics বা third-party script ব্যবহার করে না।

Copy button ব্যবহার করলে ফলাফল আপনার নিজের device-এর clipboard-এ যায়। GitHub Pages hosting-এর সাধারণ web request log এই calculator-এর control-এর বাইরে।

আপনার দায়িত্ব

সংবেদনশীল personal information, PPO number, service-book scan বা confidential employment record input না দেওয়াই ভালো। প্রয়োজন হলে anonymised বা sample value ব্যবহার করুন।

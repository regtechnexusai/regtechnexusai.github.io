Browser-only processing

এই static calculator-এর salary ও pension input browser-এর JavaScript-এ locally process হয়; calculator code এগুলো RegTech Nexus AI-এর backend-এ পাঠায় বা সংরক্ষণ করে না। তবে PayScale pages-এ Google Analytics 4 (GA4) ও Cloudflare Insights এবং calculator pages-এ Google Translate widget লোড হয়। এসব third-party service তাদের নিজস্ব নীতিমালা অনুযায়ী browsing, device ও interaction data প্রক্রিয়া করতে পারে। Third-party script উপস্থিত থাকায় confidential salary/pension বা personal data না দেওয়াই ভালো।

Copy button ব্যবহার করলে ফলাফল আপনার নিজের device-এর clipboard-এ যায়। GitHub Pages hosting-এর সাধারণ web request log এই calculator-এর control-এর বাইরে।

আপনার দায়িত্ব

সংবেদনশীল personal information, PPO number, service-book scan বা confidential employment record input না দেওয়াই ভালো। প্রয়োজন হলে anonymised বা sample value ব্যবহার করুন।

Practical launch checklist

A new market is ready only when evidence exists for each gate. These items are not marked complete by this page.

1. Local agriculture review

Confirm priority crops, local seasons, common symptom patterns, units, safe escalation and content reviewer identity.

2. Trusted local sources

Register official agricultural extension, research institutes and validated publications; record URL, date, geography and limitations.

3. Language and accessibility

Have local speakers review translations, agricultural terms, reading level, mobile layout and screen-reader labels.

4. Privacy and legal review

Review data collection, consent, retention, cross-border handling, user notices and applicable local requirements.

5. Test before release

Run mobile and desktop checks, accessibility checks, functional and regression tests, and verify that existing calculations are unchanged.

6. Named owner and feedback

Assign a local content owner, define how users report problems, and document review dates and incident escalation.

## Non-negotiable implementation boundary
This standard is presentation-only. Do not modify algorithms, business logic, calculators, calculations, validation rules, data handling, or feature behavior while restoring or applying the visual standard. Make visual changes in CSS unless a separate change is explicitly requested and reviewed.

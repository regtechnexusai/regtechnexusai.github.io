REFERENCE · OFFICIAL SOURCES

Sanctions Sources &
Download Links

A simple reference page linking directly to official sanctions, designation and related restrictive-list sources and their published formats.

Disclaimer

These links are provided for reference and access to official source materials. The links are provided as of 6 October 2026. Users must independently check the relevant official source, its latest update, applicable jurisdiction and legal requirements before relying on any information.

This page does not perform sanctions screening, matching, calculation or clearance. RegTech Nexus AI does not provide a legal determination through this page.

UN

United Nations Security Council

The UN Security Council Consolidated List is the central official list covering individuals and entities subject to Security Council sanctions measures. The official page provides PDF, XML and HTML versions.

Official Consolidated List → List Updates →
BFIU

Bangladesh Financial Intelligence Unit (BFIU)

BFIU publishes a Domestic Sanction List and provides sanctions-related resources, including UNSC sanctions implementation information. The domestic list is an important Bangladesh-specific reference.

Official BFIU Website → Domestic Sanction List — English PDF → UNSCRs Implementation Committee →
OFAC

U.S. Department of the Treasury — OFAC

OFAC's Sanctions List Service provides current sanctions-list data for download, including the SDN List and consolidated non-SDN sanctions lists.

Official Sanctions List Service → OFAC Sanctions List Service → OFAC Search / Data FAQs →
EU

European Union

The European Commission provides the official EU sanctions resources, including the consolidated list of individuals, groups and organisations subject to EU financial sanctions.

EU Sanctions Resources → EU Consolidated Financial Sanctions List → EUR-Lex — Official EU Law → EU Sanctions Map →
UK

UK Sanctions List

The UK Sanctions List is the current official source for UK sanctions designations. The UK government publishes the list in multiple formats, including XML, CSV, PDF, HTML, ODS, ODT and TXT.

Official UK Sanctions List Page → Download XML → Download CSV → Download PDF → View HTML → Download ODS → Download ODT → Download TXT →
INDIA

India — UAPA / FIU-IND Resources

India's Directorate of Enforcement (ED) is a financial-investigation and enforcement agency rather than a standalone sanctions-list publisher. For Indian designations and restrictive measures, the official MHA UAPA lists and FIU-IND sanctions resources are more appropriate.

MHA — Banned Organisations / Individuals → FIU-IND — Official Website → FIU-IND — UNSC 2231 / Targeted Financial Sanctions Resources →
PAK

Pakistan — NACTA Proscribed Persons / Organizations

Pakistan's National Counter Terrorism Authority (NACTA) provides official resources concerning proscribed persons and organizations under the Anti-Terrorism Act framework, including financial restrictions. This is a domestic restrictive-list resource, not an equivalent of OFAC or the UN list.

NACTA — Proscribed Persons → NACTA — Counter Financing of Terrorism / List Resources →

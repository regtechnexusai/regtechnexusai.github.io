5. Listening, writing and study notes

  • Listen first, repeat aloud, then read the target script.
  • Write each selected character several times and compare spacing and shape.
  • Use Bengali pronunciation as an approximation only; distinguish similar sounds by listening.
  • For formal certification, consult the official exam organiser and current syllabus.

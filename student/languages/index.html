A structured beginner pathway for Mandarin Chinese, Korean and Japanese. Learn the writing system first, then build pronunciation, vocabulary, grammar, reading, writing, listening and speaking skills with guided practice.

Standard lesson pattern

1. Learn

Script, sound, spelling and grammar explained in Bengali.

2. Practise

Listen, repeat, read, copy, write and build short sentences.

3. Review

Take a quiz, review mistakes and repeat weak items.

Learning design and quality standards

  • Teach the target script directly; use romanisation as a bridge, not a permanent substitute.
  • Provide native-script examples, Bengali meanings, clear transliteration conventions and common error notes.
  • Use audio from a reliable native-speaker or reviewed text-to-speech source when available. Audio is not yet embedded in this first release.
  • Align future learning tracks to HSK (Chinese), TOPIK (Korean) and JLPT (Japanese) only after checking current official syllabi and exam guidance.
  • Keep practice data local to the learner’s browser where used; never enter sensitive personal or banking data into learning tools.

# Contact setup

The current package keeps `regtechnexusai@gmail.com` as the verified public fallback so the website does not advertise an unconfigured mailbox.

Before changing the website to `contact@regtechnexusai.com`:

1. Create the mailbox or forwarding address.
2. Publish SPF and DKIM records for the sending service.
3. Publish a restrictive DMARC policy and monitor reports.
4. Send and receive test messages from the website address.
5. Replace the fallback address in `contact.html`, `privacy.html`, `terms.html` and any future forms.

The package includes the business office and phone details supplied for the public contact page. Validate the legal entity, registration information, governing law and retention wording before treating the legal pages as final policy documents.
